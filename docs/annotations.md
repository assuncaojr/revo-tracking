# Anotações

## Ideias, notas e pontos soltas

- Tracking consiste em pesquisas diárias que podem ser repetir na mesma região. Uma possibilidade: em um dia, uma pequisa cobre região A, no outro B e em outro C. Com isso, um bairro pode ser dividido para ter uma cobertura mais ampla, visando uma melhor coleta de dados
- O SPA deve ter um style guide/UI/UX atraente, visando uma melhor usuabilidade por parte de quem vai consumir os dados - considerando que são tecnicamente leigos no assunto
- Pesquisas podem também analisar o aspecto de candidatos a vereadores, não só prefeito.
- O SPA deve permitir que o cliente possa pedir uma analise dos dados de acordo com seu prompt
- SPA deve mostrar uma mapa de calor com base dos nados coletados
